How Canvas Notes works

What runs where, how a change gets saved, and how your data is stored · 1 November 2026

1The big picture

Canvas Notes is one small program. The browser shows the boards, and a Node server saves everything into one database file plus a folder of uploaded files. No other services are needed.

Everything lives in one data folder (DATA_DIR, by default canvasnotes/data). Copying that folder copies every account, board, card and file.

2What happens when you change a card

If you close the tab mid-save, the last changes are still sent on the way out.

3How the data is stored

The database file has five tables. Every row carries a user_id, and the server adds "only this user" to every read and write, so one account can never see or change another's data.

One card, as stored in elements.data

Boards are cards too (type: "board"). A card's parentId says which board it sits on, so boards inside boards are just a chain of parents up to Home.

4Uploading a file

Only the accounts that claimed a file can open it, unless it is on a board you published with a read-only link. Web pages, SVGs and scripts are always sent as downloads, never run.
