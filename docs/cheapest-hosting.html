Every way to host Canvas Notes — and the cheapest first month

Research from public price pages and 2026 reviews · 1 November 2026 · starting fresh (no existing data moved) · free tiers change often: check each provider before signing up

Cheapest first month: $0, with no code change. Run today's app on an Oracle Cloud Always Free virtual machine, put Cloudflare's free plan in front of notes.yashsuthar.com, and back the database up to Cloudflare R2's free 10 GB. All three are free with no time limit. The domain is the only cost, and you already pay for it.

Why this one

  • No rewrite: the same Node server, SQLite file and files folder as today; setup is a server, Caddy, a domain record and Litestream.
  • Roomy: ≈ 12 GB of memory and up to 200 GB of disk is far more than a $7 Lightsail plan (1 GB / 40 GB), and Oracle allows 10 TB of traffic a month.
  • Cloudflare in front caches images near your friends and hides the server; uploads up to 100 MB pass through, which matches the app's own limit.

The catches, and the backup plans

  • Oracle's free Arm machines are often "out of capacity" in popular regions; it can take retries or another home region. Plan B: your laptop + Cloudflare Tunnel, $0 and working today, if the laptop can stay on.
  • Oracle may reclaim free machines that sit almost idle, and reports say the free allowance was halved in 2026. Keep the R2 backup running so moving away takes minutes. Plan C: AWS credits ($100–200) pay for Lightsail for the first months, which also matches your goal of learning AWS.
  • No uptime promise on any free plan. Fine for you and friends; pay for a server (≈ $5–7) once people depend on it.

Any server above can keep its files on the disk at first and move uploads to one of these later (the "option 1" step from the earlier hosting PDF). Backups should be off the server from day one.

Plan B: your own computer + Cloudflare Tunnel ($0, works today)

A small program (cloudflared) connects out from your laptop to Cloudflare, so nothing at home is exposed and no router setup is needed. Good for a first month with friends; the app is offline whenever the laptop sleeps, and image loading is limited by your home upload speed.

The free-forever rewrite: Cloudflare Workers + D1 + R2

The cheapest option that also scales: $0 on the free plan, then $5/month. D1 is SQLite, so the database queries carry over, but the server code is rewritten for Workers (no Node file system, uploads go to R2). Worth it later if the app grows, not for the first month.

Recommendation

  1. Month 1: Oracle Always Free + Cloudflare free + R2 backups → $0, no code change. If Oracle has no capacity, use your laptop with Cloudflare Tunnel for now.
  2. Before inviting many people: add the image previews and per-board loading from the fresh-start PDF (needed on every platform).
  3. To learn AWS: use the AWS credits for a Lightsail copy next to it, or move to option 1 (S3 files) of the hosting-options PDF.
